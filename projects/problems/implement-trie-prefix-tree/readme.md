# [Implement Trie (Prefix Tree)](https://leetcode.com/problems/implement-trie-prefix-tree/)

## 问题

请你实现一棵**前缀树（字典树）**，支持以下操作。

- 构造：建立一棵空树。
- 插入：把一个单词完整写入树中。
- 查询：判断某个单词是否**完整**存在于树中。
- 前缀查询：判断树中是否存在以给定字符串为**前缀**的单词。

**示例 1**

- **输入**：`["Trie", "insert", "search", "search", "startsWith", "insert", "search"]`，`[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]`
- **输出**：`[null, null, true, false, true, null, true]`
- **解释**：插入 `apple` 后，查询 `apple` 为 `true`，查询 `app` 为 `false`；前缀 `app` 存在，因此前缀查询为 `true`。再插入 `app` 后，查询 `app` 变为 `true`。

**示例 2**

- **输入**：`["Trie", "insert", "search", "startsWith", "insert", "search", "search"]`，`[[], ["app"], ["app"], ["ap"], ["apple"], ["appl"], ["apple"]]`
- **输出**：`[null, null, true, true, null, false, true]`
- **解释**：插入 `app` 后查询 `app` 为 `true`，前缀 `ap` 存在。再插入 `apple` 后，查询 `appl` 为 `false`（它只是路径上的中间串，未作为完整单词写入），查询 `apple` 为 `true`。

**约束**

- 单词与前缀的长度均不超过 $2000$
- 所有输入只含小写英文字母
- 每个操作调用次数不超过 $3 \times 10^4$

## 解答

### 朴素想法：逐词比对

用一个列表保存所有已插入单词：查询时逐个比较，前缀查询时逐个判断前缀。每次操作都要遍历全部单词，单词总数增长后代价迅速上升。

### 共享前缀的树形组织

大量单词之间有公共前缀。把公共前缀合并成同一条路径，就能让查找只走一条路径而不用碰其它单词。每个节点代表一个前缀，边代表一个字符；单词结束的节点做一个标记，用于区分「完整单词」和「只是某个更长单词的前缀」。

### 节点内的字符分支

每个节点需要按字符定位子节点。用一张映射保存「字符 → 子节点」，插入时缺失就新建，因此单次操作只访问单词长度个节点。

### 最终算法

- 插入：从根沿字符逐级下行，缺边就新建节点；走完全词后在末节点标记单词结束。
- 查询：沿字符下行，任何一步缺边即返回 `false`；走完后返回末节点的结束标记。
- 前缀查询：沿字符下行，任何一步缺边即返回 `false`；走完即返回 `true`，不检查结束标记。

## 复杂度分析

### 时间复杂度

单次操作 $O(m)$，其中 $m$ 是单词或前缀的长度。

每步只按字符取出一个子节点，节点内的字符定位是均摊常数时间，整体只与输入串长度成正比。

### 空间复杂度

$O(S)$，其中 $S$ 是所有插入单词的字符总数。

每个不同前缀只建立一个节点，节点间的边数不超过节点数。
